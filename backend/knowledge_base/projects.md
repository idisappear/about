# Projects

## 1) SignalBoard (Personal Analytics Dashboard)

Type: Solo product (SaaS prototype)  
Timeline: January 2025 - April 2025  
Status: Active beta  

Summary:
SignalBoard is a lightweight dashboard for tracking weekly goals, habits, and project KPIs in one place.

Key features:
- Daily and weekly scorecards
- Custom KPI cards with trend indicators
- CSV import/export
- Shareable read-only links

Tech stack:
- Frontend: React, TypeScript
- Backend: FastAPI, PostgreSQL
- Infra: Render, Supabase

Outcome:
- 180 beta users
- 42% week-4 retention
- Average session time: 7.8 minutes

Role:
- Product design
- Frontend and backend implementation
- Deployment and monitoring

## 2) ClipNote (AI Notes from Video Clips)

Type: Side project  
Timeline: May 2025 - July 2025  
Status: Paused  

Summary:
ClipNote converts short video clips into structured notes with timestamps and action items.

Key features:
- Auto transcription
- Topic highlights
- Action-item extraction
- Export to Markdown and Notion

Tech stack:
- Frontend: Next.js
- Backend: Python, OpenAI API
- Storage: S3-compatible object storage

Outcome:
- 1,200 processed clips during pilot
- 68% of users exported notes at least once

Role:
- Prompt engineering
- API integration
- UX flow design

## 3) Briefly (Newsletter Summarization Agent)

Type: Internal automation tool  
Timeline: August 2025 - October 2025  
Status: In use  

Summary:
Briefly aggregates finance and tech newsletters, then generates role-specific summaries.

Key features:
- Source ingestion from RSS and email
- De-duplication of repeated stories
- Team-specific summary modes
- Daily digest delivery to Slack

Tech stack:
- Python workers
- SQLite (prototype), then Postgres
- Slack API integration

Outcome:
- Reduced reading time by ~55% for the team
- Daily digest opened by 80% of team members

Role:
- Workflow architecture
- Data pipeline implementation
- LLM response quality tuning
